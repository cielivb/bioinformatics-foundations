# Transcriptomics Concepts

## Detailed Pipeline Description
High‑throughput RNA‑seq analysis pipeline incorporating multi‑stage quality control (FastQC), adapter and low‑quality base removal (cutadapt), reference genome indexing and alignment (BWA‑MEM), coordinate‑sorted BAM generation and indexing (SAMtools), gene‑level quantification via HTSeq, and downstream statistical modelling with edgeR for dispersion estimation, quasi‑likelihood inference, and robust identification of biologically meaningful differential expression signatures.
