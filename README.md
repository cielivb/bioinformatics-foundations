# Bioinformatics Foundations

This repository contains a collection of SLURM (.sbatch) and R Markdown scripts created during my foundational bioinformatics course. It serves as a record of my early work in transcriptomics, methylation, microbiome analysis, and biological network analysis.

These scripts were written for a university HPC environment and rely on cluster‑specific modules, directory structures, and teaching datasets. They are not intended to be portable or fully reproducible outside that environment. They are provided for reference only.

## Project Structure

This repository is divided into four mini‑projects:

- **Transcriptomics:** differential expression analysis using FastQC, cutadapt, BWA, SAMtools, HTSeq, and edgeR.
- **Methylation:** TBA
- **Microbiome:** TBA
- **Networks:** TBA

Within each mini-project, you will find a collection of scripts. Each of these scripts is designed to operate in the following top-level directory structure, where each script is in the `mini-proj/scripts/` directory:

```
mini-proj/
├── data/ # Input data for mini-project (structure varies by mini-project)
├── results/ # Output folders and files generated by scripts
├── scripts/ # SLURM (.sbatch) and R Markdown analysis scripts
└── standardOE/ # Standard output/error logs from SLURM jobs
```
